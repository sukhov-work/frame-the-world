## Seeding plan — `scripts/seed-demo-pins.mjs`

Mimic the app's own client path end-to-end (the `verify-listing-member.mjs` idiom: member auth against
`wix dev`), one photo at a time:

1. **Download** the direct file URL to a temp buffer (these are JPEG/large — no RAW decode involved).
2. **Preview**: downsize to ≤2048px JPEG (script-side `sharp`, or canvas in a headless page — the client
   normally does this in `downscaleToJpeg`, `src/lib/save/uploadMedia.ts:40`).
3. **Upload** exactly as `uploadMedia.ts` does: preview via the single-PUT `generateFileUploadUrl` path
   (`uploadPreview`, `uploadMedia.ts:62`); original via TUS if >10MB (`uploadOriginal`, `uploadMedia.ts:81`
   — platform rule, CLAUDE.md).
4. **`POST /api/photos`** with a `SavePinBody` (`src/lib/wix/pinRecords.ts:31`): `title` = subject line,
   `lat`/`lon` = capture coords, `isPublic: true`, `precision: "exact"` (world landmarks, not the owner's
   location — C6 governs the owner's GPS, not these), media file ids from step 3, pose/optics fields null
   (no EXIF heading on archive shots — the frustum default is fine for demo; hand-nudge later if a specific
   pin deserves it).
5. Log the created pinId + a `#p=` share URL per pin; finish with a `usePinsStore.refresh()`-equivalent
   check — `GET /api/photos` count + a browser pass over 2–3 pins.

### Script gotchas (learned during verification — encode in `seed-demo-pins.mjs`)
- **Wikimedia rate-limits bare clients (429/403)** — send a descriptive `User-Agent` on every
  upload.wikimedia.org fetch, and fetch serially (same lesson as `warm-prod-assets.mjs`).
- Two files exceed 10 MB (Uyuni 20.8 MB · Grand Prismatic 16.6 MB) → **TUS resumable path mandatory**
  (platform rule); the rest fit the single-PUT preview path sizing after downscale.
- NOAA `oceanexplorer.noaa.gov` and `live.staticflickr.com` serve bots fine; `fws.gov` hard-blocks (403) —
  avoid USFWS URLs in automation.
- The legacy USAP photo library (`photolibrary.usap.gov`) is NXDOMAIN — Wikimedia mirrors are the live hosts
  for USAP/NOAA classics; don't chase original-agency URLs.
