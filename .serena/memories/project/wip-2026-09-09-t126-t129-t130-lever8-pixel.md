## T126 — UNDO + DROP SESSION — BUILT (both shells), twin-verified (MESH_SUITE_PLAN §16 = the design)

  the target's FULL persisted state (a building's raw `OverrideRow | null` — `t`/`s` verbatim; a model's
  `PlacementSnapshot`); per-target UNDO (the armed mesh) or global; the unchanged-since guard; BASELINE = the state

  `requestDrop(scope)` (scope bldg | model | all), DEV seams `__editJournalStore` / `__editJournal`.
