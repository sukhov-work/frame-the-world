## NAVY NIGHT-SKY ROOT CAUSE (§Item 15 — THE carried mystery; none of the suspects)
**`renderer.setClearColor(bg)` at setup converts the colour to the renderer's OUTPUT space (sRGB)
because no render target is bound** (three `getUnlitUniformColorSpace`: null target →
outputColorSpace; RT → workingColorSpace). EffectComposer runs autoClear-off, so the ONLY clear is
RenderPass's raw `renderer.clear()` — which dumps the stale sRGB-ENCODED GL state into the LINEAR
HalfFloat buffer. OutputPass treats it as linear: PBR-Neutral's black offset (x−6.25x²) eats the
red channel, sRGB encode boosts G/B → **#05070B rendered (8,26,45) on every empty sky pixel**.
Proof: composer RT readback at a sky pixel = (0.0196, 0.0275, 0.0432) = literally (5,7,11)/255 as
linear floats; hand-computing Neutral+encode reproduces the measured (8,26,45) to the unit.
**FIX: `scene.background = new THREE.Color(tokens.bg)`** (GlobeCanvas) — WebGLBackground converts
per-render-target INSIDE renderer.render (linear into the composer buffer, sRGB direct) and
force-clears over the stale state in both paths. Night sky now (2, 5.9, 10.7) mean (was
(10.8, 28.3, 46.2)).
- Companion fix (the second, elevation-dependent navy term at 20–350 km): **atmosphere Chapman
  obliquity** — exp(−h/H) weighted every ray only by closest-approach density; for UP-looking rays
  that point is the CAMERA, so a zenith ray rendered as bright as a grazing one (~30× the air).
  Now g1/g2 ×= sinLimit/max(sinEl, sinLimit), sinLimit = √(2H/(π·Re)) (line 0.077 / haze 0.155),
  mixable via ATMOSPHERE.obliquityK. Limb-passing rays (tc>0 ⇒ sinEl=0) keep pk=1 — the LEO limb
  look is pixel-untouched.

## Debug traps (paid for — reuse)
- **`document.elementsFromPoint` SKIPS `pointer-events:none` elements** — it can "prove" no DOM
  overlay while being blind to exactly the overlay class you're hunting. Enumerate
  querySelectorAll('*') + getBoundingClientRect + computed style instead.
- **Hiding the tiles groups crashes the rAF tick** (raycasts in the update loop) — the canvas
  keeps PRESENTING the last good frame, so screenshot-based bisections read "no change" for
  EVERYTHING hidden after that. Guard every measurement with a `renderer.info.render.frame`
  advance check (probe pattern in the verify script).
- **`stars.update()` re-sets `points.visible` every frame** — hide stars via `material.visible`
  (modules never touch it). Same idiom likely for other per-frame-managed objects.
- `renderer.info` auto-resets per render() call — under EffectComposer it shows only the LAST
  pass's stats (1 fullscreen triangle), not frame totals.
- DEV introspection added: `window.__composer` (GlobeCanvas, __renderer/__globe idiom).
