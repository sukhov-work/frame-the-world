## PRECISION TRAP (owner-reported "flickery/patchy" heads at close zoom) — ROOT CAUSE + FIX
ECEF ~6.4e6 m: viewMatrix(f32) × instanceTranslation(f32) on the GPU = large×large
cancellation → ~0.5 m quantisation that CRAWLS with camera motion (the PhotoFrustum lesson,
instanced edition). FIX (structural):
1. Every matrix rebuild sets `mesh.position = camera.position` on all three meshes and
   composes instance translations CAMERA-RELATIVE (`p − camera.position`).
2. Shaders use ONLY `projectionMatrix * modelViewMatrix * instanceMatrix` — the f64
   large-cancellation happens CPU-side in three's MV product. Fresnel in VIEW space
   (`V = normalize(-mvPos)`), flare billboards offset along view axes.
3. `hoverAnchor()` must ADD `heads.position` back (instance matrices are relative now).
Raycasting is unaffected (three composes matrixWorld × instanceMatrix). Verified: consecutive
close-zoom frames pixel-stable.

## Explore ambient journey (globe/explore.ts + EXPLORE tuning)
- Store seam `camera.exploreActive` / `setExplore`; nav `<a data-explore>` bound by
  `panels/ExploreMode.tsx` (entry only from idle/viewing states; unwinds FPV/temp-pin first);
  chip `.explore-chip` while active.
- Controller states: entering (cinematic flight to `poseFor(pin)` = arrivalPose at
  `altM 900_000`/`tiltDeg 50`) → dwelling (6 s + slow 0.12°/s orbit about the pin axis — the
  journey never freezes when all pins share one city) → cruising (constant-ω great-circle:
  ω = clamp(arc/`legTargetS 28`, 0.06, 0.55)°/s, `edgeRamp` 0.18/floor 0.12) → next pin;
  order = greedy `orderByNearestNeighbour` from the view focus; exhausted → re-order fresh.
- Look-ahead geometry (pure): γ = `asin((R+h)/R·sin α) − α` (≈10.9° at 900 km/50°) — camera
  rests γ BEHIND the pin; during a leg it looks γ ahead along the travel tangent, so the
  look-at lands exactly on the pin at arrival. Rays past the limb clamp to `acos(R/(R+h))`.
- `fallback` (<2 pins): fly to explore pose, idle drift owns it, RE-BEGINS when pins land
  (the welcome page arms explore before the first pins query returns).
- Exits (never fight the user): noteInteract (canvas pointer/wheel/touch) · Escape (TOP of the
  unwind chain) · encoder/slider steering (orchestrator watches rates+targets) · search fly-to.
- reduceMotion: legs = flight instant cuts + dwells, no orbit.
- Verified live: entry→dwell→2 legs (synthetic Kyiv/Odesa)→pointerdown exit clean.
  Pacing note: ramp tails make real legs ~45 s (band spec 20–40) — tune legTargetS/ramps.
